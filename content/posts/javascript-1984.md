The **1984 emulator** is now available in the browser.

This JavaScript and WebAssembly build brings the emulator to the web, allowing it to run directly in a modern browser without a separate native installation. WebAssembly handles the performance-sensitive emulation work, while JavaScript provides the browser integration and user interface.
